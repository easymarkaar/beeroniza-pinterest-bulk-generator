# Beeroniza Pinterest Bulk Generator

**Бесплатный независимый Python-клиент для массового создания изображений из Excel/CSV через REST API [Beeroniza](https://github.com/thomaspietschmann/beeroniza).**

Сделайте шаблон в Beeroniza, отметьте динамические поля и подготовьте таблицу. Скрипт автоматически загружает фоновые фотографии, передаёт тексты и цвета, ожидает рендер и сохраняет PNG/JPG/WebP на вашем компьютере. **Никакого автопостинга в Pinterest и никакого внешнего платного API не требуется** (Beeroniza устанавливается отдельно).

> **Лицензии:** этот Python-клиент распространяется по MIT. Сама Beeroniza — отдельное ПО с лицензией **Beeroniza Source Available License 1.0**, включая запрет на перепродажу и некоторые платные сервисы. Она **не** включена в этот репозиторий, и этот клиент не является официальным продуктом Beeroniza. См. [лицензию Beeroniza](https://github.com/thomaspietschmann/beeroniza/blob/main/LICENSE). Для использования и публикации собственных пинов соблюдайте права на исходные изображения и шрифты.

## Что умеет

- Читает **Excel `.xlsx`** или **CSV `.csv`**.
- Заменяет в шаблоне фон, верхний заголовок (hook) и нижний призыв (CTA).
- Для каждой строки **меняет цвет обоих текстовых слоёв** отдельно.
- Поддерживает `auto` — подбор контрастного цвета относительно указанной плашки или области фона.
- Загрузку JPG/PNG/других поддерживаемых картинок с локального диска или прямой веб-ссылки через API Beeroniza.
- Проверяет загрузку изображений и скачивает готовые картинки обратно на ваш ПК.
- Пропускает уже созданные файлы; есть `--limit`, `--force`, `--dry-run`.
- Работает на Windows и Linux, не требует Docker **на компьютере**, где запущен скрипт.

## 1. Подготовьте шаблон в Beeroniza

Запустите Beeroniza на своём сервере по [официальной инструкции](https://github.com/thomaspietschmann/beeroniza#readme). В редакторе добавьте элементы и включите для них **Dynamic**:

| Назначение | Dynamic field | Тип |
|---|---|---|
| Фоновое изображение | `background-1` | Image (или Rectangle с Fill with: Image) |
| Заголовок сверху | `hook` | Text |
| CTA-текст снизу | `cta` | Text |

Рекомендуемый размер Pinterest-изображения: **1000 × 1500**. Сохраните шаблон (**Save**).

Названия выше — стандартный пример. Для *своего* шаблона укажите его реальные имена в разделе `placeholders` файла `config.json`. Статические элементы и шрифты настраиваются в редакторе Beeroniza.

## 2. Установите генератор на Windows

1. Скачайте архив или файлы репозитория и распакуйте в папку, например `C:\PinterestGenerator`.
2. Дважды нажмите **`install_windows.bat`**. Понадобится Python 3.10+; скрипт установки создаст `.venv` и установит зависимости.
3. Скопируйте `config.example.json` в **`config.json`**.
4. Скопируйте `pins_example.xlsx` в **`pins.xlsx`**.
5. В `config.json` замените три значения своими:

```json
"base_url": "http://YOUR_SERVER_IP:8502",
"api_key": "YOUR_API_KEY",
"template_id": "PASTE_TEMPLATE_ID_HERE"
```

Это **фрагмент**, а не весь файл конфигурации. API-ключ создаётся в Beeroniza через **API Keys → Create key**. Не выкладывайте рабочий `config.json` в интернет.

Чтобы узнать `template_id` и реальные Dynamic-поля, откройте CMD в папке генератора и выполните:

```bat
.venv\Scripts\python.exe generate_pins.py --list-templates
```

## 3. Заполните Excel

`pins.xlsx` лежит **на вашем ПК**, рядом с `config.json`. Переносить Excel на VPS не требуется.

| Столбец | Значение |
|---|---|
| `filename` | Имя готового файла, например `pin_001` |
| `background_image` | **Прямая** ссылка на изображение или локальный путь (`images/bg01.jpg`) |
| `hook_text` | Верхняя надпись |
| `hook_color` | Цвет заголовка `#674839`, `auto` или пусто |
| `cta_text` | Нижняя надпись |
| `cta_color` | Цвет CTA `#FFFFFF`, `auto` или пусто |
| `format` | Необязательно: `png`, `jpg` или `webp` |

В комплекте есть **`pins_example.xlsx` и `pins_example.csv` с вымышленными ссылками `YOUR-IMAGE-HOST.example`**. Это образцы структуры, не настоящие фотографии: **обязательно замените ссылки на свои** перед реальной генерацией.

Если укажете `images/bg01.jpg`, положите файл в подпапку `images` **рядом с Excel**. Скрипт загрузит его в Beeroniza по API. Фото на сторонний хостинг заливать необязательно.

### Как работают цвета

- `#674839` → **именно** этот HEX-цвет будет применён к тексту.
- `auto` → скрипт автоматически выберет более контрастный из `light_text_color` и `dark_text_color`. Это работает при `"auto_text_colors": true` (по умолчанию).
- Пустая ячейка → скрипт **не отправляет новое значение цвета**, поэтому остаётся цвет из Beeroniza-шаблона.

**Важно:** если заголовок нарисован на однотонной плашке, задайте её цвет в `config.json`, например `"hook_overlay_color": "#FFF0B5"`. Без плашки оставьте `"hook_overlay_color": null` — программа оценит соответствующую область фоновой фотографии. У CTA работает аналогичный параметр `cta_overlay_color`. На пёстрых фонах лучше указывать HEX вручную.

## 4. Генерация в Windows CMD

Сначала проверьте первую строку:

```bat
.venv\Scripts\python.exe generate_pins.py --limit 1
```

Затем всю таблицу:

```bat
.venv\Scripts\python.exe generate_pins.py
```

Готовые файлы сохраняются в **`generated_pins`** рядом с конфигурацией, а не на VPS. Если есть такой же файл, он будет пропущен. Для повторной генерации:

```bat
.venv\Scripts\python.exe generate_pins.py --force
```

Другие полезные команды:

```bat
.venv\Scripts\python.exe generate_pins.py --dry-run --limit 2
.venv\Scripts\python.exe generate_pins.py --input other.csv --out my_pins
```

Параметр `--dry-run` всё равно проверяет доступ к Beeroniza и может скачать картинку для анализа `auto`, но **не загружает фото на сервер и не создаёт рендер-задачи**.

## 5. Linux / Ubuntu / macOS

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp config.example.json config.json
cp pins_example.xlsx pins.xlsx
# заполните config.json и pins.xlsx своими данными
python generate_pins.py --limit 1
```

Программа и Excel могут оставаться на вашем компьютере; Beeroniza работает на отдельном VPS. Если запускаете клиент на самом VPS, таблицу и локальные изображения нужно скопировать туда.

## 6. Почему может отсутствовать фон

В версии **v1.3** Python скачивает изображение, проверяет его формат и размер (до 10 МБ), загружает его в Beeroniza через `/api/v1/uploads`, читает назад для проверки и лишь затем отправляет рендер. Так устраняются проблемы с редиректами и недоступностью сторонних фотохостингов для серверного рендерера.

Если тексты появились, а центр результата белый, проверьте, что фоновый слой действительно **Dynamic → Image** и имя поля совпадает с `background-1` (или вашим значением в config). Иногда помогает использовать **Rectangle → Dynamic → Fill with Image** на заднем плане. Скрипт предупреждает о почти белой центральной области, но это лишь эвристика: намеренно белые дизайны тоже возможны.

При ошибках смотрите строки `background`, `job`, `image_url`, `SAVED` или `FAILED`. Веб-панель Beeroniza показывает список завершённых *генераций* — это не новые шаблоны.

## 7. Безопасность и публикация на GitHub

- **Никогда** не добавляйте в репозиторий `config.json`, API-ключи, пользовательские Excel/CSV, фотографии и готовые изображения. Файл `.gitignore` исключает типичные приватные файлы, но перед публикацией **проверьте список загруженных файлов**.
- В этом репозитории нет реальных API-ключей, IP-адресов, template ID или результатов пользователей.
- На HTTP-сервере ключ передаётся без шифрования. Для безопасной работы используйте **HTTPS**, ограничение доступа к панели и отдельный ключ с возможностью отзыва.
- Сам Beeroniza-проект имеет **не-MIT** лицензию с ограничениями на платные продукты и SaaS. MIT ниже относится **только к нашему самостоятельному Python-клиенту**. Не представляйте Beeroniza как OSI Open Source.
- Этот инструмент не связан с авторами Beeroniza или Pinterest и не содержит код Beeroniza.

## 8. Запуск проверок

```bash
python -m unittest discover -s tests -v
```

Тесты работают без обращения к настоящему серверу и без API-ключа. Они проверяют чтение примеров, имена плейсхолдеров, цвета и загрузку изображений через тестовый интерфейс.
